# ArgusDE

A full-control, ACP-based coding-agent desktop client — inspired by [T3 Code](https://github.com/pingdotgg/t3code) and [Orca ADE](https://github.com/stablyai/orca), but a standalone project rather than a fork of either.

**Status: early planning.** See `CLAUDE.md` for the decisions locked so far and what's still open.
